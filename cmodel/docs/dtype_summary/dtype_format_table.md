# dtype 与数据格式表

依据项目 `README.md` 的“当前支持的 dtype”和“当前支持验证的 NV MMA 硬件指令”整理。

## 总览

| dtype | 数据格式 | shape / scale | fp16 输出 |
| --- | --- | --- | --- |
| `1` | `FP16` | 默认 `m16n8k16`；`TOPOLOGY_128_INPUT=1` 时为 `m16n8k8` | 支持 |
| `2` | `BF16` | 默认 `m16n8k16`；`TOPOLOGY_128_INPUT=1` 时为 `m16n8k8` | 不支持 |
| `3` | `TF32` | 默认 `m16n8k8`；`TOPOLOGY_128_INPUT=1` 时为 `m16n8k4` | 不支持 |
| `9` | `NVFP4` / `e2m1_X_e2m1` | `m16n8k64`，`scale_vec::4X`，`ue4m3` scale | 不支持 |
| `10` | `MXFP4` / `e2m1_X_e2m1` | `m16n8k64`，`scale_vec::4X`，`ue8m0` scale | 不支持 |
| `32-56` | `F8F6F4_<A>_X_<B>` | `m16n8k32`，非 scale，覆盖 25 种 `<A>/<B>` 组合 | 支持 |
| `57-81` | `MXF8F6F4_<A>_X_<B>` | `m16n8k32`，block-scale，`scale_vec::1X`，`stype=ue8m0` | 不支持 |
| `96-119` | 整数 `s8/u8` MMA | `m8n8k16`、`m16n8k16`、`m16n8k32` | 不适用 |
| `128-151` | 整数 `s4/u4` MMA | `m8n8k32`、`m16n8k32`、`m16n8k64` | 不适用 |

## Mixed f8f6f4 / mxf8f6f4 展开表

表中每格为：`F8F6F4 dtype / MXF8F6F4 dtype`。

| A \ B | `e4m3` | `e5m2` | `e2m3` | `e3m2` | `e2m1` |
| --- | --- | --- | --- | --- | --- |
| `e4m3` | `32 / 57` | `33 / 58` | `34 / 59` | `35 / 60` | `36 / 61` |
| `e5m2` | `37 / 62` | `38 / 63` | `39 / 64` | `40 / 65` | `41 / 66` |
| `e2m3` | `42 / 67` | `43 / 68` | `44 / 69` | `45 / 70` | `46 / 71` |

## NV 硬件验证入口

| 指令类别 | 覆盖 dtype | 验证入口 |
| --- | --- | --- |
| 同构 `FP16` | `1` | `nvmac()` |
| 同构 `BF16` | `2` | `nvmac()` |
| 同构 `TF32` | `3` | `nvmac()` |
| Mixed `f8f6f4` 非 scale | `32-56` | `nvmac()` |
| Mixed `mxf8f6f4` block-scale | `57-81` | `nvmac_scale()` |
| `NVFP4` | `9` | `nvmac_scale()` |
| `MXFP4` | `10` | `nvmac_scale()` |
| 整数 MMA | `96-119`, `128-151` | `nvmac()` |
